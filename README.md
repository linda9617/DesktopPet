# Desk Cat 桌宠

跟着你的键盘和鼠标一起动的桌宠。你敲键盘它敲键盘，你的光标在哪它就看哪，你不动它就打哈欠然后睡着。支持多皮肤切换。

## 跑起来

| 方式 | 命令 |
|---|---|
| 开发运行 | `run.bat`（或 `.venv\Scripts\python.exe main.py`） |
| 打包 exe | `build.bat` → `dist\DeskCat.exe` |
| 首次装环境 | `build.bat` 会自动建 `.venv` 并装依赖 |

exe 是单文件，约 43 MB（PySide6 打包的固有体积），拷到任何 Windows 机器双击即用，不需要装 Python。

## 皮肤

右键桌宠 → 皮肤，或托盘图标右键。选择会存进配置，下次启动沿用。托盘图标和 exe 图标跟着当前皮肤变。

| 皮肤 | KEY | 说明 |
|---|---|---|
| 橘猫 | `cat` | 默认。橘白虎斑，坐在小键盘后面 |
| 云朵猫 | `cloudcat` | 白猫，轮廓是云朵形（整圈都是圆瓣）。粗描边、豆豆眼、ω 嘴、粉爪垫 |
| 芙宁娜 | `furina` | Q 版大头，纯黑豆豆眼无高光，小闭嘴笑，大礼帽 + 金冠 + 大呆毛。脸侧两束头发画在手臂**前面**，袖子从头发底下伸出来；脑后的长发垂到键盘后面 |
| 三月七 | `march7` | 粉发过肩 + 蓝发带 + 黑颈环 + 呆毛，豆豆眼带高光。整头头发一个描边一个渐变，内部靠发丝线和高光带区分；发束左右不等（左边那束比右边低 8 个单位），画在手臂**前面**，袖子从头发底下伸出来 |

**关于芙宁娜 / 三月七皮肤**：这是**用代码画的致敬形象**，不是官方美术资源，也没有复刻任何官方素材 —— 纯几何图形 + 渐变，配色和发型参考角色特征。参考图只存在本地 `skins/ref/`，不打包也不外发。自己桌面上用没问题，**不要分发或商用**。

## 它对什么有反应

| 你的动作 | 反应 |
|---|---|
| 敲左半边键盘（`qwert` / `asdfg` / `zxcvb` / Tab / Shift…） | 左手抬起敲下 |
| 敲右半边键盘 | 右手抬起敲下 |
| 空格 | 左右手交替 |
| 打字连击 | 尾巴 / 发尾摆动加快；击打是可叠加的脉冲，敲多快都跟得上 |
| 移动鼠标 | 眼珠追光标（可以瞟到眼角），头部小幅跟随 |
| 左键 / 右键点击 | 瞳孔放大、嘴微张、对应那侧耳朵 / 呆毛抖一下 |
| 静止 40 秒 | 打一个哈欠 |
| 静止 75 秒 | 闭眼低头睡着，飘 `z z z` |
| 睡着后任意键 / 点击 / 移鼠标 | 立刻惊醒 |

## 操作

| 操作 | 效果 |
|---|---|
| 左键拖动 | 移动位置，松手自动记住（支持多显示器） |
| 左键双击 | 隐藏到托盘（首次会弹一次气泡说怎么叫回来，之后不再弹） |
| 右键点它 | 菜单：皮肤、大小（75%–200%）、总在最前、回到右下角、隐藏、退出 |
| 托盘图标 | 同一个菜单（每次打开重建，勾选状态是实时的）；左键单击把它叫回最前 |

窗口无边框、背景透明、默认置顶、不占任务栏和 Alt-Tab（`Qt.Tool`）。配置存在 `%APPDATA%\deskpet\settings.json`。

## 关于键盘监听（重要）

桌宠要知道"你按了键"，但**不需要知道你按了什么**。代码是按这个原则写的：

- 按键事件在 pynput 回调**内部**就被压缩成一个字符 —— `L` / `R` / `S`（左手 / 右手 / 空格），原始 key 对象出不了那个函数。
- 不存储、不排队、不写日志、不联网。全部实现在 [inputwatch.py](inputwatch.py)，不到 80 行，可以自己读完。
- 鼠标位置**根本没挂钩子** —— 动画每帧直接读 `QCursor.pos()`，所以少一个全局监听。鼠标只监听点击。

杀毒软件可能会对全局键盘钩子报警（任何桌宠、任何快捷键工具都一样），这是 `pynput` 在用 Windows 的 `WH_KEYBOARD_LL`。

## 架构

```
main.py          组装入口：brain + window + 输入监听 + 托盘
pose.py          Pose —— 唯一的动画参数集，所有皮肤共用
pet.py           状态机：输入事件 → 连续姿态补间（脉冲衰减、指数平滑）
inputwatch.py    全局键盘 / 鼠标监听，回调内就地脱敏
window.py        透明置顶窗口、拖拽、菜单、图标生成
settings.py      %APPDATA%\deskpet\settings.json 读写
skins/
  base.py        Skin 契约 + 共用道具（键盘、zzz）+ merged() 合并剪影
  cat.py         橘猫
  cloudcat.py    云朵猫
  furina.py      芙宁娜（FurinaBase 共用身体 + FurinaSkin；头发几何是类属性的数字表）
  march7.py      三月七（头发几何全是类属性的数字表，画法一行不改就能出新版）
```

所有皮肤都是纯代码画的，没有 `assets/` 目录，`build.bat` 也没有 `--add-data`。

**关键设计**：[pose.py](pose.py) 的字段是固定词汇表，皮肤自己诠释语义 —— 猫的"耳朵抖"在芙宁娜身上是"呆毛 / 帽子抖"，"尾巴摆"是"发尾摆"。所以 [pet.py](pet.py) 完全不知道当前是哪个皮肤，加皮肤不用动状态机。

## 加一个新皮肤

1. 在 [skins/](skins/) 下新建模块，写一个 `Skin` 子类：

```python
from skins.base import Skin, pen

class MySkin(Skin):
    KEY = "myskin"          # 存进配置的标识
    NAME = "显示名"          # 菜单里显示的
    OUTLINE = QColor(...)   # 共用道具（键盘）的描边色
    ICON_CROP = (x, y, size)  # 头部方框，用来裁托盘图标

    @classmethod
    def draw(cls, p, pose):
        ...                 # 在 200x180 逻辑坐标里画
        cls.draw_keyboard(p)      # 共用键盘
        cls.draw_zzz(p, pose.zzz, cx, cy)   # 共用 zzz
```

2. 加进 [skins/\_\_init\_\_.py](skins/__init__.py) 的 `SKINS`。完事 —— 菜单、配置、图标自动跟上。

3. `python _render_check.py myskin` 渲染 9 个关键姿态成拼图，直接看对不对。

**坐标约定**：画布 200×180，`MARGIN` 另加 5px 防裁切。键盘固定在 `y 134..160`、`x 22..178`。

两种分层方式，任选一种，别混：

| 方式 | 画法 | 约束 | 用在 |
|---|---|---|---|
| 身体在键盘后 | 先画身体，再 `draw_keyboard`，手单独画在键盘前 | 下摆不超过 `y=158` | `cat` |
| 身体在键盘前 | 先 `draw_keyboard`，整只都画在它前面 | 躯干底边收在 `y≈132`（键盘上沿 134 之上），手/爪落在 `y≈146..150` | `cloudcat` `furina` `march7` |

第二种躲开了裁剪：想让爪子在键盘前、躯干在键盘后，就得给躯干加 clip，而任何宽到能放过爪子自己描边的 clip 也会把躯干一起重画到键盘上。

**画合并剪影用 [`merged()`](skins/base.py)**：把一堆重叠形状画成一个整体，只有一圈外描边。云朵猫的云瓣、芙宁娜的头发都靠它 —— 逐个描边会让头发变成一圈树叶、手臂变成搭在身上的香肠。两个单色 pass 实现，每帧零布尔运算。注意传进去的必须是**多个独立 path**，不能是一个 path 的多个 subpath（重叠 subpath 按奇偶填充，重叠处会被挖空）。

## 换皮 / 调参

- **改颜色**：各皮肤模块顶部的颜色常量。
- **改节奏**：[pet.py](pet.py) 顶部的 `TAP_DECAY`（敲击快慢）、`BLINK_TIME`、`SURPRISE_DECAY`。
- **改困倦时间**：`settings.json` 里的 `idle_yawn_s` / `idle_sleep_s`。
- **想用 PNG 素材而不是代码画**：`Skin.draw` 是唯一绘制入口，在里面 `drawPixmap` 就行，`Pose` 的字段就是需要的动画参数表。

## 开发辅助

| 脚本 | 用途 |

## 已知取舍

- 左右手判断按 QWERTY 布局硬编码，用 Dvorak / 其他布局会左右不分（不影响"在打字"这个效果本身）。
- 睡眠计时只看键盘、鼠标点击、鼠标移动，不看是否在播视频 —— 看片时它会睡着。
- 只做了 Windows。macOS 的全局监听需要辅助功能授权，另说。
- 四个皮肤目前画布尺寸相同，所以切换不改窗口大小；如果新皮肤用了不同比例，切换时窗口会变尺寸并自动收回屏幕内。
- 改过或删掉的 KEY 在 [skins/\_\_init\_\_.py](skins/__init__.py) 的 `ALIASES` 里映射到现有皮肤（`furina_derp` / `furina_derp2` / `furina_cute` / 已删除的 `furina_photo` / 曾经单列的短发版 `furina_short` → `furina`，曾经单列的长发版 `march7_long` → `march7`）。没有这张表，旧配置会静默回落到 `cat`，看起来像是程序忘了你选过哪个皮肤。
- 三月七的刘海停在眼睛上方，参考图里是压在眼睛上的。试过压上去：更接近参考图，但豆豆眼被啃掉两个缺口、高光点被盖没，而豆豆眼是这个风格里唯一的表情来源，所以退回。
- 三月七的头发画在手臂**前面**，这不是"把头发画长一点"就够的。袖子从肩膀 `y=112` 一路盖到手 `y=146`，占掉 `x 51..67` 和 `133..149`，所以任何往下垂的发束都落在袖子后面 —— 早先那版短发的头发其实已经垂到 `y≈130`，只是全被袖子挡住了，这才是它看起来像齐下巴短发的真正原因。也试过把发束往外甩躲开袖子：外轮廓从头顶到发梢一路凸出、没有缺口，读出来是"头变大"而不是"头发变长"。
- 所有发梢停在 `y≤126`：越过袖口会把手臂切断、手变成旁边飘的一个球；碰到键盘上沿 134 会画到键帽上（键盘先画）。也刻意不让头发垂过胸前 —— 那是这个尺寸下最强的长发提示，但正好压在白色小花和浅蓝披风领上，那是三月七的第三、第四个识别点。
- 呆毛只能往斜上方甩，不能立起来。画布顶到发顶只剩 14 个单位（`merged()` 的描边笔宽是 `STROKE*2`，所以描边往外凸的是整整 3 个单位，不是 1.5），立着的一撮在这点空间里只露得出自己的宽度，读出来是一只耳朵；倾到离垂直 40° 才换得出 15 个单位的长度。根也必须扎在头顶侧面（`cx+20`）而不是靠近顶点：靠近顶点时它的边和头顶轮廓几乎相切，两圈描边会挤成一个疙瘩。
- 芙宁娜脸侧的发束跟着**肩膀**掉，不跟着头掉（`LOCKS_SLUMP_LIFT`）。低头睡着时头往下掉 11 个单位、肩膀只掉 3，差的这 8 个单位会让发梢扎进金袖口的角。改成跟肩膀之后，也正好是搭在手臂上的头发该有的行为。
- 芙宁娜的发梢停在 `y≈118`，这个数是**袖口**定的不是手定的：金袖口在手前面 11 个单位，按键抬手时它会升到 `y 119..134`，所以按"手顶边 125.5"算会松 7 个单位。早先那版发束垂到 `y≈135` 并且画在手臂**后面**，发梢全藏在袖子底下 —— 看着就是头发停在肩膀，因为看不见的发梢不算长度。
- 三月七的托盘图标裁的是整个上半身（`ICON_CROP = (35, 1, 128)`），不是像别的皮肤那样只裁头。只裁头会把呆毛削顶、把发梢切掉，脸因此比别的皮肤的图标小一圈 —— 代价换的是剪影还认得出是她。
